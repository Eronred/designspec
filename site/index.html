Keep AI-written UI on your design system.

designspec reads your design system from code into a spec. Coding agents use it before they write UI, and a GitHub Action blocks pull requests that drift from it.

Why

AI agents write UI fast, but they don't know your design system. They hardcode #e5484d, invent variant="ghost2", resize a <Button> with classes and reach for <button>.

designspec tells them what to use instead, checks every pull request, and governs how the design system itself changes.

Install

$ npx designspec-cli init

Check

$ npx designspec-cli check

src/app/page.tsx
  9:22   error  Hardcoded color "text-[#1a1a1a]".
               ↳ Closest token: text-foreground
  16:24  error  "ghost2" is not a variant of Button.
               ↳ Allowed: default, destructive, outline, ghost, link
  24:36  error  "h-12" overrides the height that Button's size variant controls.
               ↳ Pick a size instead (default, sm, lg, icon)

Workflow

explore
adoption score, and the overrides and values code keeps repeating: missing variants and tokens
propose
a design system change, with the spec changes it expects
apply
sync the spec from code, migrate overrides to the new variant
verify
the code made exactly the declared changes
archive
keep the accepted proposal next to the spec
